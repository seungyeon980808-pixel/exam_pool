# 더프 4종 네이티브 미주 재감사·재제작 작업지시서

이 지침은 7월 더프, 4월 종로, 4월 대성 더프, 5월 더프의 문제·해설 PDF와
네이티브 미주 HWP/HWPX를 최신 기준으로 재감사할 때 적용한다. 기존 PASS 보고서,
수식 글꼴만 바꾼 HWPX, 문항 개수만 맞춘 결과는 최종 PASS의 근거가 아니다.

## 원본과 불변 입력

- 문제 PDF와 해설 PDF 각 8개를 원본으로 고정하고 SHA-256을 기록한다.
- 원본 PDF는 내용의 유일한 권위이며 OCR은 후보 생성에만 사용한다.
- 기존 HWP/HWPX는 복구 가능한 작업물로만 사용하고 원본을 덮어쓰지 않는다.
- 한 시험은 `COMMON-01~22`, `PROBABILITY-23~30`, `CALCULUS-23~30`,
  `GEOMETRY-23~30`의 46개 문항 ID를 사용한다.

## 필수 원본 수식 매니페스트

문제 PDF와 해설 PDF 각각에 `math-source-manifest-v1`을 작성한다.

- 모든 페이지를 600dpi로 검토하고 수식·첨자·상하한·그림 의심 영역은 900dpi로 재검토한다.
- 페이지 렌더 해시, 수식 crop 해시, PDF 좌표, 문항 ID, 순번, 원문 표기,
  MathIR, HancomEQN 스크립트, 검토 상태를 기록한다.
- `sum/prod`의 상·하한, `lim`의 변수·접근값·방향, `int`의 구간·변수를
  구조적으로 기록한다.
- 첨자·지수 소유권, 분수·근호·절댓값 범위, cases·행렬·벡터 구조를 기록한다.
- 모든 페이지와 수식은 `VERIFIED`, `uncertainties=[]`여야 한다.
- 원본 수식 수는 매니페스트의 수식 레코드 수와 정확히 같아야 한다.

매니페스트가 없거나 미검토 항목이 하나라도 있으면 HWP 생성과 최종 판정을 중단한다.

## 네이티브 생성 규칙

- 본문·정답·선지·표·조건 상자는 편집 가능한 한글 개체로 만든다.
- 수식은 `EquationCreate`의 실제 `eqed` 개체로만 삽입한다.
- 수식 글꼴은 `HYhwpEQ`, 크기는 11pt, HWPX `baseUnit=1100`으로 고정한다.
- `treatAsChar=1`, `flowWithText=1`, `allowOverlap=0`을 확인한다.
- 수식 삽입 실패 시 평문·이미지 fallback을 사용하지 않고 즉시 FAIL한다.
- 미주에는 해당 문항의 정답·본문·수식·표·그림·보충 설명 전체를 원문 순서로 넣는다.
- 미주 본문 이미지는 금지한다. 순수 그래프·기하 도형·삽화만 tight crop으로 예외 허용한다.

## 수식·미주 연쇄 게이트

각 시험에서 다음 개수와 순서가 일치해야 한다.

```text
문제 매니페스트 수식 + 해설 매니페스트 수식
= 빌더 MathIR 수
= HWPX hp:equation 수
= HWP COM 재열기 eqed 수
= 결과 PDF 수식 인벤토리 수
```

수식별 스크립트 해시와 문항 ID도 같은 순서로 일치해야 한다. 미주 46개,
자동번호 46개, 문제·해설·미주 대응 46행이 필수다. 누락·중복·오연결은 1건도 허용하지 않는다.

## HWP/HWPX 왕복과 실제 편집성

각 시험을 직렬로 처리한다.

1. 최신 구조 또는 재생성본 HWPX를 연다.
2. HWP로 저장하고 닫는다.
3. HWP를 재열어 수식·미주·표·그림을 검사한다.
4. 다시 HWPX와 PDF로 저장한다.
5. HWPX XML과 COM `ctrl_list`의 `eqed`를 전수 비교한다.
6. 모든 수식은 `EquationModify` 진입·취소가 가능해야 한다.
7. 수식 유형별 대표 식은 임시 수정 후 실행 취소한다.
8. 임시 복사본에서 공통·확통·미적분·기하 각 1문항을 복사·이동하여 미주가 따라오는지 확인한다.

COM 서버 실행 실패, 재열기 실패, 수식 편집 실패는 자동 FAIL이다.

## 이미지 감사

HWPX의 모든 XML과 BinData를 조사한다. 이미지마다 시험·문항 ID·미주번호·파일명·크기·좌표·내용·사유·허용 여부를 기록한다.

다음은 금지한다.

- PDF 페이지·문제·해설·문항 전체 캡처
- 정답·풀이·본문·수식을 포함한 이미지
- OCR 본문과 중복되는 이미지

허용된 순수 그림이라도 원본 좌표·크기·문항 소유권·해시가 매니페스트와 일치해야 한다.

## 시각 및 서식 검증

- HWP/HWPX를 PDF로 재출력한다.
- 원본과 결과를 동일한 300dpi로 렌더링한다.
- 모든 페이지의 잘림·겹침·고아 문단·빈 자리·문항 혼입을 검사한다.
- 수식은 200~300% 확대하여 상하한·첨자·지수·근호·분수·괄호 범위를 확인한다.
- 최신 기본 스타일 프로필 `수능완성_수학_문제해설_미주_기본서식_v1`을 적용한다.
- 스타일 프로필 검사는 내용 검사를 약화하지 않으며, 글꼴·문단·단·미주 간격을 별도 기록한다.

재조판으로 인한 안티앨리어싱 차이는 보조 경고일 수 있지만, 숫자·수식·문항·그림의 구조 차이는 항상 FAIL이다.

## 4종 순차 처리와 승격

1. 5월 더프 `COMMON-02`를 회귀 시범으로 검사한다.
2. 5월 전체를 PASS시킨다.
3. 7월 더프, 4월 대성 더프, 4월 종로 순서로 처리한다.
4. 한 시험의 모든 게이트가 PASS일 때만 해당 결과를 최종 폴더로 승격한다.
5. 4종 모두 PASS한 뒤 통합본을 만들고 합계·해시·재열기를 다시 검사한다.

## 최종 PASS 기준

- 원본 PDF 8개와 페이지 전부 검토 완료
- 시험별 46문항, 총 184문항의 ID·해설 일치
- 원본 수식·MathIR·HWPX·HWP COM·PDF 수식 개수 연쇄 일치
- 시그마·곱 상하한, 극한 접근조건, 적분구간, 첨자·지수, 분수·근호,
  구간별 함수·행렬·벡터 오류 0건
- 미주 참조·미주 본문·자동번호 각각 184개
- 해설 본문 이미지·수식 이미지·평문 fallback 0개
- 허용되지 않은 이미지 0개
- HWP/HWPX 재열기 4/4
- 수식 편집성 및 복사·이동 검사 4/4
- 전 페이지 시각검사와 서식검사 100%
- 차단 오류 0건

하나라도 충족하지 못하면 결과물은 `완성본`, `무오류본`, `PASS`로 표시하지 않는다.

## 저장소 반영 원칙

저장소에는 이 지침, fail-closed QA 코드, 합성 회귀 테스트만 반영한다.
저작권 PDF, 문제·해설 내용, 생성 HWP/HWPX, 원본 그림과 렌더 이미지는 커밋하지 않는다.

# ExamPool HWP 변환기 v0.1.1

Windows 설치·실행 안정성과 배포 구성을 개선한 유지보수 릴리즈입니다.

## 주요 변경 사항

- 시스템 브라우저 대신 Edge WebView2 기반 독립 프로그램 창으로 실행합니다.
- 내부 로컬 서버는 빈 포트를 자동으로 사용하고, 프로그램 창을 닫으면 함께 종료됩니다.
- 설치 패키지에서 불필요한 개발 파일을 제외해 파일 수와 설치 시간을 줄였습니다.
- 수능형 편집 가능 HWP 생성에 필요한 템플릿 16개를 설치본에 포함했습니다.
- 한글 자동화에 필요한 `FilePathCheckerModule.dll`을 설치본에 포함하고 사용자 환경에 자동 등록합니다.
- 설치된 프로그램이 개발용 Python 환경에 의존하지 않고 HWP를 생성하도록 수정했습니다.
- 기존 변환 작업과 사용자 데이터는 업데이트 설치 후에도 유지됩니다.

## 설치 및 업데이트

1. `ExamPool-HWP-Converter-Setup-0.1.1.exe`를 내려받습니다.
2. 실행 중인 ExamPool HWP 변환기를 닫습니다.
3. 설치 프로그램을 실행합니다. 기존 `v0.1.0` 위에 바로 설치할 수 있습니다.
4. 시작 메뉴 또는 바탕 화면에서 **ExamPool HWP 변환기**를 실행합니다.

Python이나 별도의 웹 서버를 설치할 필요는 없습니다. HWP 생성에는 정식 한글
프로그램 설치와 사용 권한이 필요합니다.

## 검증 결과

- Windows 설치본에서 독립 프로그램 창 실행 확인
- 설치본에 HWP 템플릿 16개 포함 확인
- 한글 보안 모듈 32비트·64비트 등록 확인
- 실제 20문항 PDF의 HWP 및 PDF 결과 생성 확인
- 설치·패키징·HWP 런타임 관련 자동화 테스트 56개 통과

## 시스템 요구 사항

- Windows 10 또는 Windows 11, 64비트
- Edge WebView2 Runtime
- HWP 생성을 위한 정식 한글 프로그램 설치 및 사용 권한
- 설치 및 로컬 OCR 모델을 위한 충분한 저장 공간
- 최초 이미지 OCR 모델 준비 시 인터넷 연결

## 알려진 제한 사항

- 자료 그림·그래프·도해는 HWP 선·도형 개체가 아니라 이미지로 들어갑니다.
- OCR 결과는 원본 해상도, 기울기, 흐림 및 글꼴에 따라 달라질 수 있습니다.
- 복잡하거나 흐릿한 수식은 변환 후 수동 확인이 필요할 수 있습니다.
- 코드 서명되지 않은 설치 파일은 Windows SmartScreen 경고가 표시될 수 있습니다.
- 한글이 설치되지 않은 PC와 macOS에서는 HWP 생성 기능을 사용할 수 없습니다.

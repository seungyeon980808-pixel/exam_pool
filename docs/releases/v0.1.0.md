# ExamPool HWP 변환기 v0.1.0

PDF와 클립보드 이미지를 수능형 HWP 문서로 변환하는 Windows용 첫 공개 버전입니다.

이 릴리즈는 ExamPool의 여러 기능 중 **PDF·이미지 → HWP 단독 변환기**만을 대상으로 합니다.

## 주요 기능

- PDF, PNG, JPG, JPEG, WebP 파일을 불러올 수 있습니다.
- 클립보드에 복사한 이미지를 `Ctrl+V`로 바로 붙여넣을 수 있습니다.
- 본문·지문·발문·보기·선지를 편집 가능한 한글 텍스트로 재구성합니다.
- 인식 가능한 분수·위첨자·아래첨자 등의 수식을 한글 수식 개체로 변환합니다.
- 문항의 자료 그림·그래프·도해는 원본 이미지 품질과 문항 내 순서를 유지해 배치합니다.
- 변환 결과를 수능형 시험지 양식의 HWP 파일로 내려받을 수 있습니다.
- 여러 파일을 한 번에 등록하고 변환 진행 상황과 이전 작업 결과를 확인할 수 있습니다.
- HwpPalette 양식을 내려받아 수정한 뒤 다시 등록할 수 있습니다.

## PDF와 이미지 처리 방식

- 텍스트 레이어가 있는 PDF는 글자, 글꼴, 위치, 벡터 도형을 분석해 문항 구조를 복원합니다.
- 스캔 PDF와 일반 이미지는 로컬 OCR로 글자와 위치를 인식합니다.
- 편집해야 하는 본문·발문·보기·선지는 텍스트와 수식 개체로 만들고, 자료 그림은 이미지로 보존합니다.

## 설치 및 실행

1. 릴리즈의 `ExamPool-HWP-Converter-Setup-0.1.0.exe`를 내려받습니다.
2. 설치 프로그램을 실행합니다.
3. 시작 메뉴 또는 바탕 화면의 **ExamPool HWP 변환기**를 실행합니다.
4. 자동으로 열린 변환 화면에서 PDF나 이미지를 선택하거나 `Ctrl+V`로 붙여넣습니다.
5. 변환이 끝나면 HWP 파일을 내려받습니다.

Python이나 별도의 웹 서버를 설치할 필요는 없습니다. 앱은 사용자 PC에서 로컬로 실행되므로 개발자 PC, Windows 서버, 도메인이 필요하지 않습니다.

## 시스템 요구 사항

- Windows 10 또는 Windows 11, 64비트
- HWP 생성을 위한 정식 한글 프로그램 설치 및 사용 권한
- 설치 및 OCR 모델을 위한 충분한 저장 공간
- 최초 이미지 OCR 모델 준비 시 인터넷 연결

## 개인정보 및 문서 처리

- 문서 분석과 OCR은 사용자 PC에서 처리합니다.
- 변환을 위해 PDF나 이미지 내용을 외부 AI 서비스로 전송하지 않습니다.
- 변환 작업 파일과 결과물은 사용자 PC에 저장됩니다.

## 현재 제한 사항

- 자료 그림·그래프·도해 자체는 HWP의 선·도형 개체가 아니라 이미지로 들어갑니다.
- OCR 결과는 원본 해상도, 기울기, 흐림, 글꼴에 따라 달라질 수 있습니다.
- `ㄱ·ㄴ·ㄷ`과 숫자·영문자가 비슷하게 보이는 저해상도 원본은 변환 후 확인이 필요합니다.
- 복잡하거나 흐릿한 수식은 일반 텍스트로 인식되거나 수동 수정이 필요할 수 있습니다.
- 원본 PDF와 완전히 동일한 줄바꿈·자간·페이지 나눔을 항상 보장하지는 않습니다.
- 한글이 설치되지 않은 PC와 macOS에서는 HWP 생성 기능을 사용할 수 없습니다.
- 코드 서명되지 않은 설치 파일은 Windows SmartScreen 경고가 표시될 수 있습니다.

## 알려진 첫 실행 특성

이미지 OCR을 처음 실행할 때 OCR 모델 준비로 시간이 더 걸릴 수 있습니다. 준비가 끝난 뒤의 변환은 첫 실행보다 빠릅니다.

## 피드백 및 오류 제보

오류를 제보할 때 아래 정보를 함께 남겨 주세요.

- Windows 버전과 한글 버전
- 입력 파일 형식(PDF, PNG, JPG 등)
- 문제가 발생한 문항의 원본 화면
- 생성된 HWP 화면
- 오류 메시지 또는 변환 단계

시험지 원본에 개인정보가 포함되어 있다면 공개 이슈에 원본 파일을 첨부하지 마세요.

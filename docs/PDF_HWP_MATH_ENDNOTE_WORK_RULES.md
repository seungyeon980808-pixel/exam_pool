# 수학 문제·해설 HWP 미주작업 지시서

## 1. 적용 시점

이 문서는 사용자가 별도로 “문제 번호 뒤 각각 미주로 해설 삽입”을 요청한 이후에만 적용한다. 현재의 문제본·해설본 변환 단계에는 미주를 넣지 않는다. 먼저 문제 HWP/HWPX와 해설 HWP/HWPX를 각각 확정하고, 담당 교사가 원하는 미주 표시·글꼴·번호 스타일을 확인한다.

## 2. 입력과 결과물

- 입력: 동일 시험의 독립 문제본과 독립 해설본, 문항 번호 매핑표, 교사 피드백.
- 결과: (1) 문제-only 원본, (2) 해설-only 원본, (3) 미주 병합본, (4) 미주 QA 보고서. 원본 파일은 덮어쓰지 않는다.
- 미주 병합본의 본문 문제·수식·그림은 기존 편집 가능 구조를 유지한다. PDF 캡처를 본문 전체에 덧씌우는 방식은 금지한다.

## 3. 미주 삽입 규칙

- 각 미주는 인쇄된 문제 번호의 텍스트 런에 실제 HWP 미주 앵커로 연결한다. 번호 뒤에 일반 본문이나 떠 있는 그림을 붙여 미주처럼 보이게 만드는 방식은 사용하지 않는다.
- 문항 하나당 미주 하나를 원칙으로 하며, 1번부터 마지막 문항까지 원문 번호와 1:1로 대응한다. 소문항·보기 안의 숫자를 별도 미주 번호로 만들지 않는다.
- 미주 본문은 해설본의 해당 문항을 그대로 옮긴다. 식·부호·답을 추론하여 바꾸지 않으며, 해설 OCR이 확정되지 않은 항목은 `[원문 대조 필요]`로 표시하고 완료 판정을 보류한다.
- 미주를 넣어도 문제 페이지의 2단, 중앙선, 보기 상자, 그림의 상대 배치는 변하지 않아야 한다. 페이지가 재흐름될 수 있으므로 앵커별로 렌더링을 반복한다.

## 4. 문항 매핑·검수

1. 문제본과 해설본에서 문항 ID(시험·페이지·문항 번호)를 만든다.
2. 모든 ID가 정확히 한 번씩 매핑되는지, 누락·중복·교차 매핑이 없는지 검사한다.
3. HWP/HWPX를 다시 열어 미주 개수와 자동번호 범위를 확인한다. 미주 번호가 본문 번호 순서와 어긋나거나 빈 미주가 있으면 실패다.
4. 문제 번호를 클릭/선택했을 때 해당 해설 미주로 이동하는지 한글에서 확인한다.
5. 전체 PDF 렌더링과 문항별 확대 검수로 미주가 본문을 가리거나 열·페이지 밖으로 떠나지 않는지 확인한다.

## 5. 수식·그림·이미지 주의사항

- 해설의 수식은 가능한 한 HWP 수식 객체로 유지한다. 원문 대조가 필요한 복잡한 도형은 이동 가능한 그림으로 둘 수 있지만, 문항 번호·본문·답을 그림으로 대체하지 않는다.
- 이미지 전용 fallback 문항은 미주 연결 전 별도 목록으로 관리한다. 원문과 수식이 확인되지 않은 상태에서 “무오류” 또는 “완료”로 표시하지 않는다.
- 미주 삽입 후에도 문제 번호·그림·보기 상자가 동일한 문제 셀에 남아 있는지 확인한다. 그림이 상단이나 다음 문항으로 이동하면 미주 삽입을 중단하고 레이아웃을 복구한다.

## 6. 완료 기준

미주 병합본은 다음을 모두 통과해야 제공한다.

- 문제·해설 문항 ID 1:1 매핑, 누락·중복 없음
- HWP와 HWPX 재개방 성공, 미주/자동번호 수 일치
- 문제 번호 순서와 미주 앵커 순서 일치
- 원본과 같은 2단·보기·그림 배치 및 페이지 흐름
- 수식·숫자·부호의 원문 대조 기록과 미확정 항목 목록
- 미주가 없는 문제-only·해설-only 원본과 별도 병합본 보존

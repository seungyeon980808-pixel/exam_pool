# 평가원 기출 기반 문항 텍스트 스타일 명세

> 상태: v1.0 · 2026-08-11 실측
>
> 목적: ExamPool이 문항을 작성할 때 실제 평가원 시험에서 확인되지 않은 문장 골격을 임의로 만들지 않게 한다.

## 1. 강제 원칙

1. **내용은 새로 만들 수 있지만 문장 골격은 새로 만들 수 없다.**
2. 지문·발문·보기·선지의 고정 표현은 이 명세의 `frame_id` 중 하나를 사용한다.
3. 프레임의 대괄호 슬롯 안에만 대상, 상황, 기호, 수치, 물리량을 넣거나 바꾼다.
4. 프레임 밖의 조사·연결어·종결어미를 바꾸면 새로운 문장 골격으로 취급한다.
5. 새로운 프레임은 실제 기출의 시험지·문항 번호를 확인하고 등록한 뒤에만 사용할 수 있다.
6. 출처가 없는 프레임은 “평가원식”, “수능식”이라고 부르지 않는다.

이 규칙의 “실제 시험 문장”은 문항 전체를 복사한다는 뜻이 아니다. 예를 들어
`그림은 [대상]을 나타낸 것이다.`에서 `[대상]`은 새 문항에 맞게 바꿀 수 있지만,
`그림을 보고 다음 물음에 답해 보자.`처럼 고정 골격 자체를 새로 만드는 것은 금지한다.

## 2. 분석 말뭉치

| 항목 | 값 |
|---|---:|
| 과목 | 평가원 물리학Ⅰ |
| 기간 | 2007학년도 수능 ~ 2027학년도 6월 모의평가 |
| 포함 시험 | 수능·6월 모의평가·9월 모의평가 |
| 중복 제거 시험지 | 54개 |
| 문항 | 1,080개 |
| 문항 분할 성공 | 1,080/1,080, 실패 0개 |
| 선택지 추출 단위 | 4,969개 |

원본은 로컬 기출 보관소의 `p1_YYYY_MM.pdf`이며, 같은 파일명의 복사본은 한 번만 셌다.
재현 가능한 집계 결과는 `PRD/11_KICE_ITEM_TEXT_STYLE_DATA.json`, 분석기는
`tools/analyze_kice_text_style.py`에 둔다.

이 말뭉치는 고등학교 물리학Ⅰ이므로 **문장 문법과 시험 표현**의 근거로 사용한다.
중학교 문항에는 같은 골격을 쓰되 정보량, 수식, 변인 수, 추론 단계는 중학교 수준으로 낮춘다.

## 3. 실측 핵심 결과

### 3.1 도입 방식

| 도입 프레임 계열 | 문항 수 | 비율 |
|---|---:|---:|
| `그림 (가)와 (나)는 ...` | 329 | 30.5% |
| `그림은 ...` | 324 | 30.0% |
| `그림과 같이 ...` | 205 | 19.0% |
| `다음은 ...` | 117 | 10.8% |
| `표는 ...` | 13 | 1.2% |
| 기타 | 92 | 8.5% |

`나타낸 것이다.`는 831문항(76.9%), `모습을 나타낸 것이다.`는 226문항에서 확인됐다.
따라서 그림·표의 도입은 설명을 길게 덧붙이지 않고 무엇을 나타내는지 한 문장으로 특정하는 것을 기본으로 한다.

### 3.2 발문 방식

| 발문 계열 | 문항 수 | 비율 |
|---|---:|---:|
| `옳은 것만을 <보기>에서 있는 대로 고른 것은?` | 651 | 60.3% |
| 구형 `옳은 것을 <보기>에서 모두 고른 것은?` | 42 | 3.9% |
| `그래프로 가장 적절한 것은?` 등 가장 적절형 | 40 | 3.7% |
| 직접 `...로 옳은 것은?` | 25 | 2.3% |
| `옳은 학생만을 있는 대로 고른 것은?` | 24 | 2.2% |
| `옳게 비교한 것은?` | 8 | 0.7% |
| 그 밖의 수치·비·배열·짝짓기형 | 264 | 24.4% |
| PDF 글꼴 문제로 물음표를 추출하지 못한 문항 | 46 | 4.3% |

정확히 `이에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?`인 문장은
600회 확인됐다. 반면 현재 ExamPool에서 생성했던
`이에 대한 설명으로 옳은 것만을 고른 것은?`은 **0회**였다. 후자는 사용 금지다.

### 3.3 조건과 부정 발문

| 항목 | 문항 수 | 비율 |
|---|---:|---:|
| `<보기>` 사용 | 729 | 67.5% |
| `(단, ...)` 조건 사용 | 365 | 33.8% |
| `옳지 않은`, `아닌 것은` 계열 | 0 | 0.0% |

이 말뭉치에서는 부정 발문이 한 번도 확인되지 않았다. 평가원형 자동 작성의 기본값은 긍정 발문이며,
부정 발문은 사용자가 학교 시험용으로 명시적으로 요구할 때만 별도 스타일로 허용한다.

## 4. 허용 프레임

### 4.1 지문·자료 도입

| frame_id | 허용 골격 | 적용 |
|---|---|---|
| `INTRO_FIGURE_SINGLE` | `그림은 [대상·상황]을 나타낸 것이다.` | 그림 1개 |
| `INTRO_FIGURE_PAIR` | `그림 (가)와 (나)는 각각 [상황 A]와 [상황 B]를 나타낸 것이다.` | 두 장면 비교 |
| `INTRO_FIGURE_AS_SHOWN` | `그림과 같이 [조건·행동]한다.` | 그림 자체가 조건을 보여 줄 때 |
| `INTRO_NEXT_DESCRIPTION` | `다음은 [대상]에 대한 설명이다.` | 설명·자료 상자 |
| `INTRO_NEXT_EXPERIMENT` | `다음은 [현상]에 대한 실험 과정이다.` | 과정만 제시 |
| `INTRO_NEXT_EXPERIMENT_RESULT` | `다음은 [현상]에 대한 실험 과정과 결과이다.` | 과정과 결과 제시 |
| `INTRO_TABLE` | `표는 [대상·측정 결과]를 나타낸 것이다.` | 표 중심 문항 |
| `INTRO_DIALOGUE` | `그림은 [주제]에 대해 학생 A, B, C가 대화하는 모습을 나타낸 것이다.` | 학생 대화형 |

운영 규칙:

- `다음은` 뒤에는 반드시 설명, 실험, 탐구 과정처럼 실제로 뒤따르는 자료의 종류를 쓴다.
- `그림은` 뒤에서 교과서식 배경 설명을 추가하지 않는다. 풀이에 필요한 조건만 다음 문장에 둔다.
- 그림이 둘이면 `(가)`, `(나)`의 대응 관계를 문장 안에서 분명히 한다.
- 자료에 없는 원인이나 해석을 도입문에서 미리 설명하지 않는다.

### 4.2 합답형 발문

| frame_id | 허용 골격 | 비고 |
|---|---|---|
| `ASK_BOGI_STANDARD` | `이에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?` | 기본, 최근형 |
| `ASK_BOGI_TARGET` | `[대상]에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?` | 지시 대상이 모호할 때 |
| `ASK_BOGI_STUDENT` | `제시한 내용이 옳은 학생만을 있는 대로 고른 것은?` | 학생 대화형 |
| `ASK_BOGI_PERSON_OLD` | `[결과]에 대해 옳게 말한 사람을 <보기>에서 모두 고른 것은?` | 구형 자료 재현에만 사용 |

`ASK_BOGI_STANDARD`를 기본으로 사용한다. `<보기>`가 실제로 존재하지 않으면 합답형 발문을 쓰지 않는다.
`옳은 것만을 고른 것은?`, `모두 선택한 것은?`, `맞는 내용을 모두 고르시오.`처럼 중간 요소를 생략하거나
명령형으로 바꾼 문장은 허용하지 않는다.

### 4.3 직접 선택형·그래프형·배열형 발문

| frame_id | 허용 골격 | 적용 |
|---|---|---|
| `ASK_DIRECT_CORRECT` | `[대상]으로 옳은 것은?` | 값·대상·개념 직접 선택 |
| `ASK_DESCRIPTION_CORRECT` | `[상황]에 대한 설명으로 옳은 것은?` | 5개 진술 중 하나 선택 |
| `ASK_GRAPH_BEST` | `[물리량 관계]를 나타낸 그래프로 가장 적절한 것은?` | 그래프 선택 |
| `ASK_COMPARE_CORRECT` | `[대상 A와 B]를 옳게 비교한 것은?` | 비교표·비교 선지 |
| `ASK_ORDER_CORRECT` | `[A, B, C]를 순서대로 옳게 나타낸 것은?` | 배열형 |
| `ASK_RATIO` | `[물리량 A] : [물리량 B]는?` | 비 계산 |
| `ASK_VALUE` | `[구하려는 물리량]은?` | 수치 계산 |

`가장 적절한`은 그래프·모형·관계 표현처럼 근사적 표현 중 최선안을 고를 때 사용한다.
사실 진술 하나의 정오를 물으면서 습관적으로 `가장 적절한`을 붙이지 않는다.

### 4.4 조건문

| frame_id | 허용 골격 |
|---|---|
| `COND_IGNORE` | `(단, [무시할 요인]은 무시한다.)` |
| `COND_CONSTANT` | `(단, [일정한 물리량]은 일정하다.)` |
| `COND_SAME` | `(단, [두 대상의 공통 조건]은 같다.)` |
| `COND_DEFINED` | `(단, [기호]는 [정의]이다.)` |

조건은 발문 뒤 괄호 안에 둔다. 이미 그림·표·앞 문장에 제시한 조건을 반복하지 않는다.
`공기 저항은 무시한다.`는 실제로 무시해야만 답이 정해질 때만 쓴다.

### 4.5 보기·선지 문장

- 한 보기에는 판단 가능한 주장 하나를 둔다.
- 진술형은 현재형 평서문 `-다.`로 끝낸다.
- 비교는 기준을 생략하지 않고 `A에서가 B에서보다 크다.`처럼 쓴다.
- 방향·위치·대소·증감의 기준을 문장 안에 둔다.
- 단위와 기호는 자료에서 사용한 표기와 동일하게 유지한다.
- 합답형 선택지는 `ㄱ`, `ㄴ`, `ㄱ, ㄴ`처럼 조합만 제시한다.
- 직접 선택형은 완전한 문장, 수치·단위, 대응표 중 기출에서 확인된 형식을 따른다.
- 해설에 들어갈 인과 설명을 선지에 불필요하게 덧붙이지 않는다.

## 5. 금지 문체

다음 표현은 자동 생성에서 금지한다.

- 말뭉치 0회인 축약 발문: `이에 대한 설명으로 옳은 것만을 고른 것은?`
- 학습지 명령형: `알맞은 답을 고르시오.`, `모두 선택하시오.`, `찾아보자.`
- 대화형 존댓말: `무엇일까요?`, `확인해 보세요.`
- 메타 표현: `위 그림을 참고하여`, `주어진 정보를 바탕으로`, `다음 질문에 답하시오.`
- 불필요한 교과서 설명: 이미 그림으로 평가할 내용을 지문에서 정답처럼 설명하는 문장
- 근거 없는 강조: `항상`, `절대로`, `반드시`, `완전히`를 오답 표지처럼 넣는 방식
- 한 문장 안에서 조건, 관찰, 해석, 결론을 모두 연결하는 장문
- `<보기>`가 없는데 `<보기>`를 언급하거나, `<보기>`가 있는데 언급을 생략한 합답형 발문

단, 위 목록의 표현이 향후 실제 기출에서 확인되면 출처와 용도를 등록한 뒤 허용할 수 있다.

## 6. 생성 절차

1. 문항 유형과 자료 유형을 결정한다.
2. 같은 유형의 실제 기출을 최소 3개 검색한다.
3. 허용된 `frame_id`를 하나 선택한다.
4. 프레임의 슬롯에만 새 내용과 수치를 넣는다.
5. 고정 골격을 정규화하여 등록된 프레임과 일치하는지 검사한다.
6. 지문·발문·보기·선지마다 스타일 출처를 기록한다.
7. 사실 근거 검사와 문체 검사를 모두 통과한 뒤에만 완성 후보로 표시한다.

권장 출처 기록 형식:

```json
{
  "frame_id": "ASK_BOGI_STANDARD",
  "sources": [
    {"paper": "p1_2009_11.pdf", "item": 1},
    {"paper": "p1_2017_11.pdf", "item": 2},
    {"paper": "p1_2026_11.pdf", "item": 3}
  ]
}
```

## 7. 자동 검증 계약

문체 검증기는 다음 결과를 반환해야 한다.

| code | 수준 | 조건 |
|---|---|---|
| `style_frame_missing` | 오류 | 지문·발문에 `frame_id`가 없음 |
| `style_frame_unattested` | 오류 | 등록되지 않은 고정 골격 사용 |
| `style_frame_modified` | 오류 | 허용 슬롯 밖의 조사·연결어·종결어미 변경 |
| `bogi_reference_missing` | 오류 | 합답형인데 발문에 `<보기>`가 없음 |
| `bogi_reference_orphan` | 오류 | `<보기>`가 없는데 발문이 이를 언급함 |
| `negative_style_unrequested` | 오류 | 사용자가 요구하지 않은 부정 발문 |
| `style_source_missing` | 오류 | 실제 시험지·문항 번호 출처가 없음 |
| `choice_claim_overloaded` | 경고 | 하나의 보기에 독립 주장 여러 개가 결합됨 |
| `condition_redundant` | 경고 | 앞 자료와 같은 조건을 반복함 |

완성 조건은 오류 0개다. “평가원과 비슷해 보인다”는 사람의 인상만으로 통과시킬 수 없다.

## 8. 프레임 추가 절차

1. 로컬 기출 PDF에서 같은 골격을 검색한다.
2. 시험지, 문항 번호, 원문을 기록한다.
3. 3회 이상 확인된 골격은 일반 프레임 후보로 등록한다.
4. 1~2회만 확인된 골격은 대표 페이지를 육안 검증하고 제한 용도를 명시한다.
5. 분석 데이터와 이 문서를 함께 갱신한다.
6. 문체 검증 테스트를 추가한다.

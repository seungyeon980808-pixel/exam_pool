# 평가원 도해 스타일 가이드

> 목적: ExamPool 문항의 자료 그림을 **평가원 형태로** 그리기 위한 시각 문법.
> Claude가 5E MCP로 그림을 그리기 전에 이 문서를 읽고 적용한다.
>
> 근거: 물리 기출 30회분(2017~2026, 6·9·11월)에서 추출한 그림 **617장 전수 분석** (2026-07-25).
> 원본 그림: `assets/kice_figures/` (git 제외), 유형 분류: `assets/kice_figures/figures.json`의 `type` 필드.
> 여러 분석 배치에서 독립적으로 반복 관찰된 규칙만 수록했다.

## 0. 대원칙 3가지

1. **완전 무채색.** 모든 그림은 흑백+회색조. 순검정 채움은 의미 있는 곳(스펙트럼 띠, 자성체 끝면)에만 극히 제한적으로 쓴다.
2. **선 굵기 2단 위계.** 본체(물체·광선·그래프 곡선)는 굵은 실선, 보조(법선·안내선·치수선)는 확연히 가는 선. 대략 2~3배 차이.
3. **물체는 추상화.** 물체는 원칙적으로 무장식 사각형(내부에 질량 기입)으로 그리고, 실험 기구(저울·스탠드·수레)만 구체적 형태로 그린다.

## 1. 선 (Line)

| 선 종류 | 용도 |
|---|---|
| 굵은 실선 | 본체: 물체 윤곽, 광선, 파형, 그래프 곡선, 도선, 궤도·빗면 |
| 가는 실선 | 좌표축, 치수선, 라벨 지시선(꺾임 없는 직선), 수평면(1줄) |
| 가는 파선(dashed) | **법선**, 그래프 값 안내선(축으로 투영), 수평 기준선, 자기장 영역 경계, 궤도 |
| 파선 윤곽(같은 도형 반복) | 물체의 **이전/가상 위치** — 현재는 실선(+회색 채움), 과거는 파선 속 빈 도형 |
| 점선(dotted) | 대칭축, 굴절 전 진행 연장선 |

- 직각 관계는 반드시 작은 **ㄱ자(정사각형 모서리) 기호**로 명시한다 (법선-계면, 수직 낙하 등).
- 확대(줌인)는 파선 원/사각형으로 두르고 가는 실선(또는 파선) 2가닥으로 확대 그림과 연결한다.
- 파동의 마루는 실선, 골은 파선 — 그림 하단에 범례(— 마루 ---- 골)를 반드시 병기한다.
- 전류가 흐르는 도선·레일은 가는 이중선+회색 채움 띠로 그려 수학적 단선과 구분한다.

## 2. 서체 — 3단 체계

| 대상 | 서체 | 예 |
|---|---|---|
| 물리량 기호 | **세리프 이탤릭** (수식체) | v, m, F, θ, λ, I |
| 물체·지점 이름, 숫자, 단위 | **세리프 정체(로만)** | A, B, C(물체·대문자) / p, q, r(지점·소문자) / 4 m/s |
| 한글 라벨 | **고딕 정체** | 수평면, 마찰 구간, 광원, 벽 |

- 첨자는 절반 크기 아래첨자: v₀, t₁, θ₂, I_A — 첨자가 물체명·숫자면 정체 유지.
- 계수는 기호 앞에 붙임: 2m, 3L, 0.6c (숫자 정체 + 기호 이탤릭). 분수는 세로쌓기.
- 숫자와 단위는 좁게 띄움: "4 m/s", "20 m". 단위는 항상 정체.
- 질량·크기 값은 **물체 사각형 내부**에, 물체 이름(A, B)은 **사각형 외부**에 (이중 라벨 체계).
- 지점은 검은 점(●) + 바로 옆 소문자 로만.
- 한글 라벨은 대상 바로 옆에 두고, 멀면 가는 지시선(화살촉 없음)으로 연결.
- 회색 배경 위 라벨은 흰 테두리(halo)를 둘러 가독성 확보. (5E text의 halo 기본값과 일치)
- "수평면" 라벨의 정위치: 바닥선 오른쪽 끝 아래. 정지 상태는 물체 위에 한글 "정지"를 직접 표기.

## 3. 화살표

| 종류 | 그리는 법 |
|---|---|
| 힘 | 굵은 실선 + 채운 삼각형 머리. 물체 표면에서 바깥으로. 기호(F)는 화살촉 옆 |
| 속도·운동 방향 | 힘보다 가늘게, 물체 옆에 짧게. 기호(v, 2v)를 화살표 위에 |
| 광선 | 굵은 실선의 **경로 중간**에 화살촉을 얹는다 (끝점이 아님) |
| 치수(거리) | 가는 양방향 화살표(↔) + 양끝 짧은 종단선. 값은 중앙. 범위 끝은 파선 연장선으로 한정 |
| 광자·빛·전자기파 | 물결선(~~~) 끝에 화살촉 — 직선 화살표와 구분 |
| 열·일·에너지 흐름, 상황 전환 | 폭 넓은 **회색 블록 화살표** (벡터와 구분). 위에 한글 설명 |
| 좌표축 | 가는 선 끝에 채운 화살촉 1개 |
| 회전·공전 | 궤도 곡선 위 작은 곡선 화살표 |

- 화살촉은 **속이 찬 삼각형 단일 스타일**이 기본.
- 에너지 준위 전이: 가는 수직 화살표, 흡수는 위·방출은 아래. 방출 광자는 물결 화살표 병행.

## 4. 음영 — 해칭 금지, 회색 명도 단계

- **빗금 해칭은 쓰지 않는다.** 벽·바닥·매질·마찰 구간 전부 균일한 회색 면(플랫 그레이) 채움.
- 매질·영역 구분은 회색 명도 3~4단계(흰색→연회색→진회색)로. 예: 공기=흰색, 굴절률 큰 매질일수록 진하게. 매질 이름은 영역 내부에 한글로.
- 마찰 구간: 바닥선·빗면 위에 굵은 회색 띠 + "마찰 구간" 라벨(+지시선).
- 벽·천장: 연회색 채움 사각형 + "벽"/"천장" 라벨.
- 자석: N/S 칸을 회색/흰색으로 나누고 문자 병기.
- 기체 분자는 작은 흰 원(○)을 흩어 그림. 전하는 원 안 +/- 기호(종류별 흰/회색 채움 대비).
- 입체감은 2~3단계 명암(윗면 흰색, 옆면 회색)까지만. 구·행성은 방사형 그라데이션 허용.

## 5. 그래프

- 두 축 모두 가는 실선 + 끝에 채운 화살촉. **원점은 숫자 '0'** (문자 O가 아님)을 교차점 좌하단에.
- **격자는 기본적으로 없음.** 특정 값만 가는 파선 안내선으로 곡선→축 투영하고, 축에 기호 눈금(t₀, 2V₀, 3I₀)을 단다. 구체 숫자보다 **기호 배수**가 표준.
- 데이터 곡선은 축보다 훨씬 굵은 실선. 두 계열이면 실선 vs 파선 + 곡선 끝에 A, B 텍스트 라벨 (범례 상자 없음).
- 축 라벨: "물리량(단위)" 형식 — 시간(s), 속력(m/s). 세로축 라벨은 축 위쪽에 가로쓰기(길면 2줄), 가로축 라벨은 화살촉 오른쪽 아래.
- 축 일부 생략은 물결 기호(≈)를 축 위에.
- 데이터 점은 채운 검은 점(●) + 대문자 라벨.
- 열역학 순환(P-V): 상태점 ●+대문자, 경로 중간 화살촉으로 진행 방향, "등온"·"단열"을 곡선 옆 한글로.
- 그래프 아래 면적 강조: 연회색 채움 + 면적값을 흰 halo 글자로.

## 6. 표

- 전 칸 **가는 단일 실선의 닫힌 격자** — 외곽선도 같은 굵기, 굵은 테두리 강조 없음.
- 헤더 행은 음영·굵은 글씨 없이 본문과 동일 처리. 셀은 중앙 정렬.
- 셀 값: 물리량은 이탤릭 기호, 미지값은 원문자 ㉠㉡㉢, ○/× 기호를 쓰면 표 아래 괄호로 의미 정의.
- 열 제목에 단위 괄호 병기: 전기 전도도(1/Ω·m).

## 7. 배치·구성 문법

- **(가)(나) 좌우 병렬**이 표준 포맷. 특히 "(가) 상황도 + (나) 그래프" 조합이 전체의 약 1/5. 캡션 (가)(나)(다)는 각 부분 그림의 **하단 중앙**에.
- 두 상황 비교는 같은 축척·같은 구도로 반복해 차이점만 드러낸다. 시간 순서(전/후)는 세로로 쌓고 왼쪽에 한글 상황 라벨.
- 실험 문항: 전체를 가는 실선 박스로 감싸고 〔실험 과정〕〔실험 결과〕 표제 + (가)(나)(다) 순번, 장치도·표·그래프를 한 박스에.
- 대화형 문항: 상단 칠판/패널(자료) + 하단 학생 2~3명 회색조 일러스트 + 둥근 모서리 말풍선(꼬리는 화자 방향) + "학생 A/B/C" 라벨.
- **⊙/× 자기장 기호를 쓰면 그림 아래 범례 문장 필수**: "×: xy 평면에 수직으로 들어가는 방향" 형식.
- 실험 과정 순번은 (가)(나)(다), 결과 계열은 원문자 ㉠㉡㉢, 영역·구간은 로마 숫자 Ⅰ Ⅱ Ⅲ.
- 에너지 준위도: 굵은 수평선, 왼쪽 에너지 값(-0.54 eV), 오른쪽 양자수(n=2) 좌우 정렬 고정 양식.

## 9. ExamPool(중학교) 적용 노트

이 문법은 수능 물리 기출에서 추출했다. 중학교 시험에 적용할 때:

- **문법(선·서체·화살표·음영·배치)은 그대로** 따른다 — 이것이 "평가원 느낌"의 본체다.
- 내용 수준은 낮춘다: 기호 배수 눈금(3I₀) 대신 간단한 수치, 첨자 최소화.
- 성취기준 유의사항 준수 — 예: [9과10-01]은 "굴절 법칙은 정량적으로 다루지 않는다" → 광선도에 각도 수치를 굳이 넣지 않는다.
- 정보량을 줄인다: 한 그림에 (가)(나) 2패널 이하, 라벨 5개 이하를 기본으로.

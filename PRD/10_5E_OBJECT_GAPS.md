# 5E 객체 갭 목록 — 기출 부품 인벤토리

> 목적: "그림을 그리다가 도구가 없어서 원시 도형으로 흉내 내는" 상황을 없앤다.
> 근거: 추출한 기출 그림 617장 중 **371장을 유형별로 전수·표본 조사**(2026-07-26).
> 조사 원본: 유형별 JSON 7개(분석 세션 산출물). 총 **174종**의 미지원·부분지원 부품 확인.

## 읽는 법

- **none** = 5E에 대응 도구가 아예 없음 (원시 도형으로도 재현 곤란)
- **partial** = 비슷한 게 있으나 **형태가 평가원 관례와 다름** (예: 5E 다이오드는 삼각형+막대, 평가원은 p/n 2칸 블록)
- 빈도 = 조사 표본에서 등장한 그림 수

## 4. 만들 필요 없다고 확인된 것

온도계 · 불꽃 아이콘 · 단열재 해칭 · 추(분동) — 열역학·파동 47장에서 **0회**.
평가원은 단열을 해칭이 아니라 지시선 텍스트로, 가열을 불꽃이 아니라 블록 화살표 Q로,
추 대신 모래로 표기한다. (조사로 얻은 반례 — 감으로 만들었으면 낭비였을 항목)

## 5. 구현 방식 판단 기준

| 조건 | 방식 | 예 |
|---|---|---|
| 길이·각도·개수가 **변수** | **파라미터 타입** (`pendulum` 선례, 12개 파일) | 용수철, 파면, 필드 격자, 준위 세트 |
| 모양 고정, 크기만 변함 | **SVG 에셋** (`svg-assets.js` + `templates.js` 1줄) | 사람, 손, 우주선, 계측기 |
| 기존 타입의 **형태 변형** | **variant/kind 추가** | 천장 도르래, 2칸 소자 블록 |
| 기존 타입의 **옵션 부족** | **필드 추가** | lineMode `wavyArrow`, funcgraph 면적 채움 |
| 드물게 쓰는 조합물 | **퍼스널 오브젝트**(코드 없음) | 일회성 장치도 |

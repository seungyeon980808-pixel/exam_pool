# DocFinder — 규정 빠른검색기 (로컬 전용)

지정한 폴더 안의 PDF 매뉴얼·규정을 키워드로 즉시 검색해, **어느 문서 몇 페이지**에 있는지 일치율 순으로 찾고 클릭 한 번에 그 페이지를 띄워줍니다. 인터넷 없이 동작하며 문서를 외부로 보내지 않습니다.

## 실행 방법

- **가장 쉬운 방법**: `DocFinder 실행.bat` 더블클릭
- 또는 이 폴더에서 터미널로: `npm start`

## 사용법

1. 상단 **폴더 선택** → 검색할 PDF들이 든 폴더 지정 (하위 폴더 포함해서 자동 색인)
2. 검색창에 키워드 입력 — **띄어쓰기로 여러 개를 넣으면 모두 포함(AND)하는 페이지만** 찾습니다
   - 예: `수행평가 부정행위`, `선거 동표`, `학교폭력 재심`
3. 왼쪽 결과 목록: 일치율(%) · 파일명 · 페이지 · 문맥 미리보기 (키워드 노란 하이라이트)
4. 결과를 클릭하면 오른쪽에 **해당 PDF의 그 페이지**가 뜹니다. **원본 열기**로 기본 PDF 뷰어에서도 열 수 있습니다.
5. 폴더 내용이 바뀌면 상단 **재색인** 버튼을 누르세요.

## 기술 개요

- Electron + pdf.js(미리보기) + 순수 JavaScript BM25 색인(검색)
- 색인·설정 저장 위치: `%APPDATA%\docfinder\`
- 네이티브 모듈 없음 → Windows에서 별도 빌드도구 불필요

## 검증 상태 (2026-07-12)

실제 매뉴얼 14개(2183페이지) 기준으로 검증 완료:
- 색인 약 20초, 검색 40여 ms
- "수행평가 부정행위" → 학교규정 24페이지(부정행위 0점 처리 조항)를 100% 일치율로 정확히 검색
- 미리보기 렌더 + 페이지 내 키워드 하이라이트 정상

## 폴더 구조

```
docfinder/
├── src/
│   ├── main/           # 메인 프로세스
│   │   ├── main.js     # 앱 생명주기 + IPC
│   │   ├── indexer.js  # 폴더 스캔 + PDF 텍스트 추출 + 색인
│   │   └── search.js   # BM25 AND 검색
│   ├── preload.js      # 렌더러↔메인 안전 통신
│   └── renderer/       # 화면(UI) + pdf.js 미리보기
├── test/               # 색인·검색 검증 스크립트
└── DocFinder 실행.bat
```
